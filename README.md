
# Bank Account Simulation

## Project Description
Bank Account Simulation is a console-based Java application
that demonstrates basic banking operations using Object-Oriented
Programming (OOP).

## Features
- View account details
- Deposit money
- Withdraw money
- Prevent invalid deposits and withdrawals
- Check insufficient balance
- Maintain transaction history
- Interactive menu using the console

## Technologies Used
- Java
- VS Code
- Terminal
- Git and GitHub

## Project Structure
Bank-Account-Simulation/
├── Account.java
├── Main.java
├── README.md
└── .gitignore

## Prerequisites
- Java JDK installed
- Terminal or VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal in the project folder.
3. Compile the Java files:

   javac Account.java Main.java

4. Run the program:

   java Main

## OOP Concepts
- Classes and objects
- Encapsulation
- Constructors
- Methods
- Object instantiation

## Note
This is an educational simulation. It does not connect to a
real bank or process real financial transactions.
